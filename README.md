Lightweight Keyboard Overlay for OBS, still at code development, maybe making it to an EXE file in the future

How to use it for now:

get the files
copy the path to the main folder (MonkeyTypeOverlay)
use the terminal in VSCode and type "cd "PATH of the overlay's main folder""
use "npm start"
right click "index.html" and open it with live server


now it should work as intended showcasing the keyboard with real-time input
